## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22 runs `main.ts` directly. It validates `entry.png` (regular file, at most 1048576 bytes / 1 MiB, PNG signature, 1024×1024 dimensions) and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
